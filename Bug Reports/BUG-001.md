# BUG-001 — Registration accepts an invalid password

**Environment:** UAT  
**Browser:** Chrome 151  
**Severity:** Medium  
**Priority:** High  
**Status:** Open

## Description

The registration form allows a user to create an account with a password shorter than the minimum required length.

## Preconditions

- User is on the registration page.
- User is not authenticated.

## Steps to Reproduce

1. Open the registration page.
2. Enter a valid email address.
3. Enter `123` in the password field.
4. Fill in the remaining required fields.
5. Click **Register**.

## Expected Result

The system should reject the password and display a validation message indicating the minimum required password length.

## Actual Result

The system accepts the password and creates the account.
