# Чек-лист: Smoke E2E з Адміністратором (Критичний шлях)

**Мета:** Перевірити повний наскрізний процес: Реєстрація Постачальника -> Модерація Адміном -> Створення товару -> Реєстрація Покупця -> Пошук та Оформлення B2B-замовлення -> Чат та обробка замовлення.

Крок 1. Постачальник: Реєстрація та створення B2B-профілю
[ ] 1.1. Реєстрація:

Перейти на сторінку реєстрації (/register).

Заповнити форму реєстрації Постачальника (Email, Пароль, Назва компанії, ЄДРПОУ/Реквізити).

Натиснути «Зареєструватися».

Очікуваний результат: Акаунт створено, відображається статус «На модерації» / «Очікує підтвердження адміністратором».

[ ] 1.2. Авторизація:

Спробувати увійти в кабінет Постачальника (/login).

Очікуваний результат: Успішний вхід, функції створення товарів заблоковані до схвалення Адміном.

Крок 2. Адміністратор: Модерація та активація Постачальника
[ ] 2.1. Вхід в Адмінку:

Відкрити панель управління (/admin).

Увійти з обліковими даними Адміністратора.

[ ] 2.2. Модерація компанії:

Перейти в розділ «Заявки / Нові постачальники».

Знайти компанію, зареєстровану на Кроці 1.

Натиснути «Схвалити / Активувати».

Очікуваний результат: Статус компанії змінився на «Активний».

Крок 3. Постачальник: Публікація гуртового товару
[ ] 3.1. Створення картки товару:

Повернутися в кабінет Постачальника та оновити сторінку.

Перейти в «Товари» -> «Додати товар».

Заповнити: Назва, Категорія, Гуртова ціна, Мінімальна партія (наприклад, від 10 шт.), Опис, Зображення.

Натиснути «Зберегти та відправити на модерацію».

[ ] 3.2. Модерація товару (в Адмінці):

В Адмінці (/admin/products) знайти новий товар та натиснути «Схвалити».

Очікуваний результат: Товар переходить у статус «Опубліковано» та стає доступним у каталозі.

Крок 4. Покупець: Реєстрація, пошук та B2B-замовлення
[ ] 4.1. Реєстрація Покупця:

Відкрити режим «Інкогніто» або інший браузер.

Зареєструвати акаунт Покупця (Email, Пароль, ПІБ/Компанія).

[ ] 4.2. Пошук товару:

Ввести в рядок пошуку назву товару з Кроку 3.

Перейти в картку товару.

Очікуваний результат: Назва, фото, гуртова ціна та мінімальний квант (від 10 шт.) відображаються коректно.

[ ] 4.3. Оформлення замовлення:

Вказати кількість товару (наприклад, 15 шт., щоб дотриматися мін. партії).

Натиснути «У кошик» -> Перейти до оформлення (/checkout).

Заповнити адресу/реквізити та підтвердити замовлення.

Очікуваний результат: Замовлення створено (наприклад, #1001), статус «Нове».

Крок 5. B2B-Чат та зміна статусів замовлення
[ ] 5.1. Чат з боку Покупця:

У деталях замовлення #1001 відкрити чат з Постачальником.

Написати повідомлення (наприклад, «Доброго дня! Чи прикріпили документи?»).

[ ] 5.2. Чат та обробка замовлення Постачальником:

Переключитися у вікно Постачальника -> Розділ «Вхідні замовлення».

Відкрити замовлення #1001 та перевірити наявність вхідного повідомлення в чаті.

Відповісти в чаті та перевести статус замовлення з «Нове» у «Підтверджено / В обробці».

Очікуваний результат: Повідомлення доставлено Покупцеві, статус замовлення оновився у обох сторін.
